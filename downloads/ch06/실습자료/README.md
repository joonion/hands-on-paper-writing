# 6장 표와 그림 실습자료

이 폴더에는 6장 실습에서 표와 그림의 작성·검증·연결 과정을 연습할 수 있도록 검증된 예시 산출물을 모아 두었습니다. 이 자료는 학습자의 실제 연구 결과가 아니므로, 논문의 근거로 그대로 사용하지 마세요.

- `tables/`: 표로 정리한 분석 결과 CSV
- `figures/`: 간접효과와 경로모형 그림의 PNG·PDF
- `scripts/`: 표와 그림을 생성한 R 스크립트
- `logs/`: 생성 환경과 입력 파일 목록

표·그림과 로그의 원본은 `analysis/04_outputs/publication_20260819_181131`에 있으며, 생성 스크립트의 원본은 `analysis/02_scripts/tables_figures.R`입니다. 생성 기록에 따르면 이 자료는 2026년 8월 19일에 생성되었습니다. 실습에서는 표와 그림의 값을 임의로 수정하지 말고, 스크립트·로그·입력 목록을 이용해 출처와 생성 과정을 추적하세요.
