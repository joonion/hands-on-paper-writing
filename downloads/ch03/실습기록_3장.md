## 최종 점검

- [ ] 맞춤형 지침, 메모리와 프로젝트 정보를 구분했다.
- [ ] 저장할 메모리는 학생이 직접 승인하고 실제 저장 상태를 확인했다.
- [ ] 모호한 요청과 구조화된 요청을 같은 기준으로 비교했다.
- [ ] 연구자가 결정한 조건과 아직 결정하지 않은 조건을 구분했다.
- [ ] 에이전트의 작업 대상, 권한, 금지 행동, 승인과 완료 기준을 명시했다.
- [ ] 공개 논문의 연습용 복사본만 사용하고 원본을 변경하지 않았다.
- [ ] AI의 완료 보고가 아니라 실제 파일과 PDF 원문을 직접 확인했다.
