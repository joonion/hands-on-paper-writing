\### 작성 원칙

- 실제 데이터 분석에서 확인된 결과만 사용하세요.
    
- 새로운 분석 결과나 수치를 임의로 생성하지 마세요.
    
- `연구설계.md`에서 계획한 분석과 실제 수행한 분석이 다른 경우 변경 내용과 이유를 명시하세요.
    
- 사전에 계획된 분석과 탐색적 추가 분석을 명확하게 구분하세요.
    
- p-value뿐 아니라 가능한 경우 효과크기와 신뢰구간을 함께 보고하세요.
    
- 통계적 결과와 그에 대한 해석을 구분하세요.
    
- 데이터가 뒷받침하는 범위를 넘어 인과관계나 일반화를 주장하지 마세요.
    
- 선행연구와의 비교, 이론적 의미, 학술적·실천적 시사점은 아직 작성하지 마세요.
    
- 동일한 결과를 여러 절에서 불필요하게 반복하지 마세요.
    
- 표와 그림에는 일관된 번호와 제목을 사용하세요.
    
- 결정되거나 분석되지 않은 사항은 `분석하지 않음` 또는 `해당 없음`으로 표시하세요.
    
- 학술적이고 명료한 표현을 사용하세요.
    
- Markdown 형식으로 작성하세요.
