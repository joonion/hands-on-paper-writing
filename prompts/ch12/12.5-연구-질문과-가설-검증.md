[맥락]
- 연구 질문과 가설: [`연구설계.md`에서 확정한 연구 질문, 가설과 연구 모형]
- 분석 계획: [`연구설계.md`에서 확정한 질문·가설별 변수, 분석방법, 가정과 보고 지표]
- 분석용 자료: [12.2에서 확정한 분석용 자료와 변경 기록]
- 기술통계와 측정 검토: [12.3~12.4에서 확인한 자료 특성과 측정의 신뢰성·타당성 결과]
- 실행 환경: [12.1에서 기록한 소프트웨어, 패키지, 버전과 난수 시드]

[지시]
- 각 연구 질문과 가설을 분석 대상, 변수, 모형식과 분석방법에 연결하여 실행 전 점검표를 작성하세요.
- 변수 코딩, 기준범주, 통제변수, 결측치 처리와 분석 표본을 `연구설계.md`와 대조하세요.
- 각 분석의 가정과 전제조건을 확인하고 사전에 계획한 대안의 적용 여부를 결정하세요.
- 승인된 분석 환경에서 재현 가능한 코드로 사전 계획 분석을 실행하고 코드와 원 출력을 보존하세요.
- 연구 질문과 가설별로 분석 표본 수, 추정치, 불확실성, 효과크기와 신뢰구간 및 방법에 적합한 검정 결과를 보고하세요.
- 사전에 계획한 민감도·강건성 분석이 있다면 주요 분석과 구분하여 수행하고 결론에 미치는 영향을 설명하세요.
- 계획하지 않은 추가 분석이 필요하면 목적과 이유를 먼저 제시하고 연구자가 승인한 경우에만 `탐색적 분석`으로 수행하세요.
- 분석 계획과 실제 수행이 달라진 경우 변경 내용, 이유, 결정 시점과 결론에 미칠 가능성을 기록하세요.

[조건]
- 12.4의 중대한 측정 문제가 해결되지 않은 상태에서 주요 분석을 진행하지 마세요.
- 실제 코드를 실행하고 확인한 출력만 보고하며 수치나 검정 결과를 임의로 생성하지 마세요.
- 유의한 결과를 얻기 위해 변수, 표본, 모형 또는 분석방법을 반복하여 바꾸지 마세요.
- 사전 계획 분석, 민감도·강건성 분석과 탐색적 분석을 명확히 구분하세요.
- 통계적으로 유의하지 않은 결과를 효과가 없다는 증거로 단정하지 마세요.
- 통계적 결과와 연구적 해석을 구분하고, 연구설계가 허용하지 않는 인과관계를 주장하지 마세요.
- 질적 또는 혼합연구라면 해당 연구방법에 맞는 코딩·해석·통합 절차와 신뢰성 확보 방법을 사용하고 통계적 검정을 강요하지 마세요.
