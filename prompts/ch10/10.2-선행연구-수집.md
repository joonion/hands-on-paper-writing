앞서 세운 검색 전략을 실제 학술 검색원에 적용하여 선행연구를 수집하고 검색·선별 과정을 기록하세요.

[맥락]
- 연구 질문: [`연구기획.md`에서 도출한 연구 질문]
- 검색 전략: [기존 대화에서 수립한 검색어, 검색식과 검색원]
- 포함·제외 기준: [기존 대화에서 정한 문헌 포함·제외 기준]
- 검색 결과: [사용자가 학술 검색원에서 확인한 검색 결과 또는 접근 가능한 검색 결과]

[지시]
- 검색원별로 검색일, 검색식과 검색 결과 수를 기록하세요.
- 중복 문헌을 확인하고 중복 제거 전후의 문헌 수를 기록하세요.
- 각 문헌의 제목, 저자, 발행연도, 학술지 또는 출처, 권·호·쪽수와 DOI 또는 확인 가능한 링크를 정리하세요.
- 각 문헌이 어떤 연구 질문과 관련되는지 설명하세요.
- 포함 또는 제외 판단과 그 이유를 기록하세요.
- 각 문헌의 접근 상태를 `[원문 확인]`, `[초록만 확인]`, `[서지정보만 확인]`으로 구분하세요.
- 포함 문헌, 제외 문헌과 서지정보를 확인하지 못한 문헌을 별도의 목록으로 정리하세요.

[조건]
- 학술 검색원이나 출판사 페이지에서 존재와 서지정보를 확인한 문헌만 포함하세요.
- 학술 검색원에 직접 접근할 수 없다면 접근할 수 없는 범위를 먼저 알리고 사용자에게 검색 결과를 요청하세요.
- 존재를 확인하지 못한 논문, DOI, 링크 또는 서지정보를 임의로 생성하지 마세요.
- 원문을 확인하지 못한 문헌의 연구 방법, 결과 또는 한계를 추론하지 말고 `[원문 확인 필요]`로 표시하세요.
- 검색 결과를 확인한 뒤 특정 결과에 유리하도록 포함·제외 기준을 임의로 변경하지 마세요.
