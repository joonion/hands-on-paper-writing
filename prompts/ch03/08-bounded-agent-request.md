`literature` 폴더의 PDF 파일만 읽고, 각 논문의 제목·저자·연도·연구 질문·연구 방법을 `literature-map.md`에 표로 정리해 줘. 원본 PDF의 이름을 바꾸거나 이동하거나 삭제하지 마. 내용이 확인되지 않는 항목은 추측하지 말고 빈칸으로 남겨 줘. 먼저 작업 계획과 발견한 파일 목록을 보여 주고, 내가 승인하면 표를 작성해 줘. 완료한 뒤에는 사용한 파일과 확인하지 못한 항목을 함께 보고해 줘.
