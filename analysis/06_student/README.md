# 12장 학생용 실습자료

이 묶음은 「생성형 AI 학습중심 활용과 대학생의 학업성취도 간의 관계: 자기조절학습의 간접효과」를 예시로 자료 분석을 연습하기 위한 자료입니다.

## 반드시 확인하세요

- 모든 자료는 실제 학생에게서 수집하지 않은 완전한 합성자료입니다.
- 실제 연구결과나 실제 참여자 자료로 제시해서는 안 됩니다.
- `01_raw/`의 원자료는 수정하지 않습니다.
- 통계 프로그램에 익숙하지 않다면 `04_jamovi/ch12_starter.omv`를 열어 jamovi 경로로 시작합니다.
- R을 사용할 수 있다면 `06_R/README_R.md`를 읽고 빠른 분석 또는 전체 재현 경로를 선택할 수 있습니다.
- jamovi와 R을 모두 실행할 필요는 없습니다. 선택한 경로의 실제 출력과 기록을 제출합니다.
- ChatGPT가 작성한 수치와 해석은 분석 결과가 아닙니다. 반드시 선택한 프로그램의 실제 출력과 대조합니다.

## 폴더와 파일

| 위치 | 역할 | 학생이 할 일 |
|---|---|---|
| `01_raw/` | 네 개의 합성 원자료 | 12.1~12.2에서 파일 구조와 품질 문제를 확인하고 원본은 보존합니다. |
| `02_codebook/` | 변수 정의, 값 라벨, 정제 규칙과 표본 흐름 | 원자료와 분석용 자료를 해석할 때 기준으로 사용합니다. |
| `03_analysis-ready/` | 승인된 정제 규칙을 적용한 최종 분석용 자료 | R 빠른 분석이나 CSV 확인에 사용합니다. |
| `04_jamovi/` | 변수 유형을 설정한 jamovi 시작 파일 | 12.3부터 기본 분석 경로로 사용합니다. |
| `05_worksheet/` | 단계별 분석 기록지 | 선택한 프로그램의 출력에서 직접 확인한 값을 `analysis-record.md`에 기록합니다. |
| `06_R/` | 패키지 확인, 빠른 분석과 전체 재현 R 코드 | R 선택 심화 경로에서 사용합니다. |
| `manifest-sha256.csv` | 배포 파일의 SHA-256 해시 | 원자료가 바뀌지 않았는지 확인할 때 사용합니다. |

## 시작 순서

1. ZIP 파일을 옵시디언 볼트 아래에 압축 해제합니다.
2. 이 문서와 `02_codebook/SYNTHETIC_codebook.md`를 먼저 읽습니다.
3. 12.1~12.2에서는 `01_raw/`의 파일을 열어 구조와 품질 문제를 확인하되 수정하지 않습니다.
4. 다음 중 한 경로를 선택합니다.
    - jamovi: `04_jamovi/ch12_starter.omv`를 열고 `ch12_working.omv` 사본으로 저장합니다.
    - R 빠른 분석: `06_R/run_quick_analysis.R`을 실행합니다.
    - R 전체 재현: `06_R/run_full_analysis.R`을 실행합니다.
5. 12.3~12.7의 분석을 실행하면서 `05_worksheet/analysis-record.md`를 채웁니다.
6. 실제 출력과 기록지를 근거로 `자료분석.md`를 작성하고 12.9에서 다시 대조합니다.

R 경로의 준비 방법, 명령과 결과 폴더는 `06_R/README_R.md`에서 확인합니다.
