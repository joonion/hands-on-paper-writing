# 합성자료 코드북 요약

이 문서는 학생이 12장 실습에서 자주 확인할 내용을 요약한 것입니다. 전체 변수 정의와 생성 검증 정보는 `SYNTHETIC_codebook.xlsx`를 기준으로 합니다.

## 자료의 성격

- 실제 참여자가 없는 완전한 합성자료
- 모집대상 186명을 가정한 시간차 설문·시험성적 자료
- 연구모형: T1 생성형 AI 학습중심 활용(LCU) → T2 자기조절학습(SRL) → T3 기말고사 성적
- 통제변수: T1 SRL 평균, 중간고사 원점수

## 원자료 파일

| 파일 | 내용 | 연결 변수 |
|---|---|---|
| `SYNTHETIC_00_roster_raw.csv` | 186명의 연구용 명부와 분반 | `study_id` |
| `SYNTHETIC_01_T1_survey_raw.csv` | 동의, LCU 6문항, T1 SRL 6문항 | `entered_study_id` |
| `SYNTHETIC_02_T2_survey_raw.csv` | T2 SRL 6문항 | `entered_study_id` |
| `SYNTHETIC_03_exam_scores_raw.csv` | 중간·기말고사 성적과 응시 상태 | `study_id` |

## 분석용 자료의 주요 변수

| 변수 또는 변수군 | 측정 수준 | 의미 |
|---|---|---|
| `study_id` | ID | 직접식별정보가 아닌 합성 연구용 연결 ID |
| `section` | 명목 | 모의 수업 분반 A, B, C |
| `LCU1_T1`~`LCU6_T1` | 순서 | T1 생성형 AI 학습중심 활용 문항, 1~5점 |
| `SRL1_T1`~`SRL6_T1` | 순서 | T1 자기조절학습 문항, 1~5점 |
| `SRL1_T2`~`SRL6_T2` | 순서 | T2 자기조절학습 문항, 1~5점 |
| `LCU_T1_mean` | 연속 | LCU 6문항 평균 |
| `SRL_T1_mean` | 연속 | T1 SRL 6문항 평균 |
| `SRL_T2_mean` | 연속 | T2 SRL 6문항 평균 |
| `midterm_score` | 연속 | 중간고사 원점수 |
| `final_score` | 연속 | 기말고사 원점수 |
| `synthetic_flag` | 명목 | 합성자료 표시이며 모든 행이 1이어야 함 |

## Likert 값

| 값 | 의미 |
|---:|---|
| 1 | 전혀 그렇지 않다 |
| 2 | 그렇지 않다 |
| 3 | 보통이다 |
| 4 | 그렇다 |
| 5 | 매우 그렇다 |

모든 LCU와 SRL 문항은 정방향입니다. 합성점수는 해당 여섯 문항에 모두 응답한 경우의 평균입니다.

## 기본 정제 원칙

1. 원자료는 읽기 전용으로 보존합니다.
2. 연구용 ID의 공백, 대소문자와 하이픈 형식을 표준화합니다.
3. 표준화한 ID를 명부와 대조합니다.
4. 중복 응답은 문항 완성도가 높은 응답을 우선하고, 동률이면 더 늦은 응답을 선택합니다.
5. 비동의, 필수 문항 불완전, 명부 미연결 사례를 구분하여 제외합니다.
6. T1·T2 설문과 중간·기말고사 자료가 모두 유효한 사례를 최종 분석에 사용합니다.
7. 짧은 응답시간이나 동일 응답 반복만으로 사례를 자동 제외하지 않습니다.

정제 결과를 임의로 다시 만들지 말고, 12.3부터는 검증된 `ch12_analysis_ready.csv` 또는 `ch12_starter.omv`를 사용하여 `analysis-record.md`에 실제 출력값을 기록합니다.
