## 12.8~12.9 최종 점검

- [ ] 모든 수치는 선택한 프로그램의 실제 출력에서 직접 확인했다.
- [ ] N, 추정치, 신뢰구간과 p 값을 옮긴 뒤 원 출력과 다시 대조했다.
- [ ] 통계적 유의성과 효과의 크기를 구분했다.
- [ ] 비유의 결과를 효과가 없다는 뜻으로 단정하지 않았다.
- [ ] 간접효과를 인과효과로 표현하지 않았다.
- [ ] 원자료와 제공된 시작 파일·코드를 수정하지 않고 작업 사본 또는 실행 결과를 보존했다.
- [ ] jamovi와 R 중 선택한 경로 및 프로그램·패키지 버전을 기록했다.
- [ ] ChatGPT가 제안한 수치나 출처를 확인 없이 추가하지 않았다.
- [ ] 미완료 결과는 `[분석 실행 필요]`, 근거가 부족한 해석은 `[결론 유보]`로 표시했다.
