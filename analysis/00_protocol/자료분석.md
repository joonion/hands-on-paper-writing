## 2. 분석 환경과 재현 정보

연구설계에서는 R을 사용하고, `psych`를 신뢰도·기술통계에, `stats`를 회귀·상관분석에, `mediation`을 bootstrap 매개효과 분석에 사용하도록 계획하였다.

실제 사용한 `analysis_pipeline.R`에서 확인된 주요 설정은 다음과 같다.

| 설정 | 값 | 상태 |
|---|---:|---|
| Bootstrap 반복 | 5,000회 | 연구설계와 일치 |
| 신뢰수준 | 95% | 연구설계와 일치 |
| 가설검정 유의수준 | .05 | 분석 코드에 명시 |
| 분석 시드 | 20260819 | 분석 코드에 명시 |
| 예상 표본수 검증 | `STRICT_EXPECTED_COUNTS = TRUE` | 코드에 명시 |
| 합성자료 확인 | `REQUIRE_SYNTHETIC_FLAG = TRUE` | 코드에 명시 |

`analysis_pipeline.R`은 원자료를 수정하지 않고 별도의 파생자료와 결과 파일을 생성하며, 입력 파일 manifest, 패키지 버전, `sessionInfo()`, 원자료 실행 전후 무결성 정보를 로그로 저장하도록 작성되어 있다.

그러나 현재 제공된 자료에는 실제 실행 시 저장된 `package_versions.csv`, `sessionInfo.txt`, `raw_file_integrity_check.csv`가 포함되어 있지 않다. 따라서 실제 실행에 사용된 R 버전과 `psych`, `mediation`의 버전 및 원자료 무결성 로그는 이 문서에서 최종 확인할 수 없다. [결론 유보]

표·그림 재생산을 위해 `tables_figures.R`과 전체 실행 래퍼 `run_full_pipeline.R`이 작성되어 있다. `tables_figures.R`은 검증된 분석 출력 CSV를 입력으로 하여 표·그림만 재생산하고, 회귀모형이나 bootstrap을 다시 적합하지 않도록 분리하였다.

현재 제공된 자료에는 이 후처리 코드로 실제 생성된 최종 PNG/PDF 표·그림 파일이 포함되어 있지 않다. 따라서 최종 시각화 파일의 실제 생성 여부는 [분석 실행 필요]이다.

## 3. 자료 품질과 처리 결정

### 3.1 자료 연결과 ID 처리

원자료에서 명부·시험자료의 ID 변수는 `study_id`, 설문자료의 입력 ID는 `entered_study_id`로 구분되어 있다. 코드북의 정제 규칙에 따라 다음 순서로 표준화하도록 분석 코드에 구현하였다.

1. 앞뒤 공백 제거
2. 대문자화
3. `ALG26###` 형식의 하이픈 복구
4. roster의 `study_id`와 대조

수정 가능한 ID 오류는 정제 과정에서 표준화하고, roster와 연결되지 않는 ID는 별도 audit 자료로 기록하도록 하였다.

### 3.2 중복 응답

코드북에 따라 동일 ID의 중복 응답은 문항 완성도가 높은 응답을 우선하고, 완성도가 같으면 더 늦게 제출된 응답을 선택하였다. 실제 표본 흐름에서 T1은 원자료 183행에서 고유 응답자 180명, T2는 169행에서 고유 응답자 168명으로 정리되었다.

### 3.3 유효응답 및 최종 분석대상

T1은 연구동의와 LCU 6문항·SRL 6문항의 완전응답, T2는 SRL 6문항의 완전응답을 기준으로 하였다. 시험자료는 중간·기말고사 점수가 모두 확보되고 응시상태가 유효한 사례를 사용하였다. 최종적으로 T1, T2, T3가 연구용 ID로 정확히 연결된 완전자료를 주 분석에 포함하였다.

응답시간이 짧거나 동일응답 패턴이 있는 사례는 자동 제외하지 않고 검토 플래그로만 관리하였다. 이는 연구설계에 별도의 자동 제외기준이 없고 코드북도 단독 제외를 요구하지 않기 때문이다.

### 3.4 새로운 표본 제외·변수 변환

가설검정을 위해 추가적인 사례 제외, 문항 삭제, 통제변수 변경, 모형 변경은 수행하지 않았다. 회귀 진단에서 영향 가능 사례가 확인되었으나 이를 근거로 표본을 사후 제외하지 않았다.

## 5. 측정 검토

### 5.1 LCU T1

LCU는 6문항 평균으로 산출하였다. 실제 분석에서 Cronbach's α=.851, 표준화 α=.851, 평균 문항간 상관=.487이었다. 문항별 수정된 문항-총점 상관(`r.drop`)은 모두 양의 값이었으며 최솟값은 .559였다.

판단: 본 표본에서 6문항 LCU 점수의 내적 일관성에 뚜렷한 문제는 확인되지 않았다. 신뢰도 결과만으로 단일차원성 또는 구성타당성이 입증되었다고 해석하지 않았다.

### 5.2 SRL T1

T1 SRL은 6문항 평균으로 산출하였다. Cronbach's α=.828, 표준화 α=.828, 평균 문항간 상관=.445였다. `r.drop`의 최솟값은 .538이었다.

판단: T1 SRL의 내적 일관성에 뚜렷한 문제는 확인되지 않았다.

### 5.3 SRL T2

T2 SRL은 동일한 6문항 평균으로 산출하였다. Cronbach's α=.795, 표준화 α=.794, 평균 문항간 상관=.392였다. `r.drop`의 최솟값은 .470이었다.

판단: T2 SRL의 내적 일관성은 분석에 사용할 수 있는 수준으로 확인되었으며, 결과에 맞추어 특정 문항을 삭제하지 않았다.

### 5.4 타당도와 시험점수

현재 분석 출력은 LCU와 SRL의 내적 일관성을 확인하지만, Cronbach's α는 단일차원성이나 구성타당도의 충분한 증거가 아니다. 연구설계에는 번안 및 전문가 검토가 계획되어 있으나 실제 전문가 검토 기록은 현재 제공자료에서 확인되지 않는다. [결론 유보]

중간·기말고사는 객관적 수행자료로 사용하였지만, 시험문항별 신뢰도, 시험 청사진, 채점자 일치도, 분반 간 시험·채점의 동등성 자료는 현재 제공자료에 포함되어 있지 않다. 따라서 시험성적의 측정품질을 별도로 확정하지 않는다. [결론 유보]

추가 CFA, EFA 또는 T1-T2 측정동일성 분석은 사전 연구설계에 포함되지 않았으며 본 주 분석에서 새로 실시하지 않았다.

## 6. 질문 분석·가설 검정

최종 분석표본 N=162를 유지하고 연구설계에 명시된 두 회귀모형과 5,000회 bootstrap 매개효과 분석을 적용하였다.

### 6.1 RQ1 / H1

RQ1: 대학생의 생성형 AI 학습중심 활용(LCU)은 이후의 자기조절학습(SRL)을 정적으로 예측하는가?

매개변수 모형:

`SRL_T2 ~ LCU_T1 + SRL_T1 + Midterm`

| 항목 | 결과 |
|---|---:|
| N | 162 |
| LCU T1 B | 0.292 |
| SE | 0.064 |
| 표준화 β | .293 |
| 95% CI | [0.165, 0.419] |
| t | 4.543 |
| p | <.001 |
| 모형 R² | .414 |
| 조정 R² | .403 |
| F(3,158) | 37.282 |
| 모형 p | <.001 |

통계적 결과: T1 SRL과 중간고사 점수를 통제한 후 LCU T1의 회귀계수는 양(+)이며 통계적으로 유의하였다.

가설 판단: H1 지지.

### 6.2 RQ2 / H2

RQ2: 대학생의 자기조절학습(SRL)은 이후의 학업성취도를 정적으로 예측하는가?

종속변수 모형:

`Final ~ SRL_T2 + SRL_T1 + LCU_T1 + Midterm`

| 항목 | 결과 |
|---|---:|
| N | 162 |
| SRL T2 B | 3.400 |
| SE | 1.433 |
| 표준화 β | .174 |
| 95% CI | [0.569, 6.231] |
| t | 2.372 |
| p | .019 |
| 모형 R² | .507 |
| 조정 R² | .494 |
| F(4,157) | 40.368 |
| 모형 p | <.001 |

통계적 결과: T1 SRL, LCU T1, 중간고사 점수를 통제한 후 SRL T2의 회귀계수는 양(+)이며 통계적으로 유의하였다.

가설 판단: H2 지지.

### 6.3 RQ3 / H3

RQ3: 생성형 AI 학습중심 활용(LCU)과 학업성취도 간의 관계에서 자기조절학습(SRL)의 통계적 간접효과는 유의한가?

5,000회 bootstrap 결과:

| 효과 | 비표준화 추정치 | 95% bootstrap CI | p |
|---|---:|---:|---:|
| 간접효과 | 0.992 | [0.167, 2.105] | .014 |
| 직접효과 | 0.576 | [-1.866, 2.911] | .663 |
| 총효과 | 1.568 | [-0.768, 3.848] | .193 |

주 분석에서 비표준화 간접효과는 0.992, 95% bootstrap CI [0.167, 2.105], p=.014였다. 효과크기 해석을 보조하기 위해 추가로 산출한 표준화 간접효과는 .051, 95% bootstrap CI [.009, .108], p=.014였다.

통계적 결과: 사전 계획된 H3의 판단은 비표준화 간접효과와 5,000회 bootstrap 95% 신뢰구간을 기준으로 하였으며, 해당 신뢰구간은 0을 포함하지 않았다.

가설 판단: H3 지지.

표준화 간접효과는 사전 연구설계에 명시되지 않은 추가·보조 분석으로 구분한다. 직접효과와 총효과도 H1~H3의 별도 사전 가설이 아니라 매개효과 해석을 위한 보조 결과로 구분하며, 그 비유의 결과를 “효과가 없음”의 증거로 단정하지 않는다.

## 9. 질문별 결과와 해석

이 절에서는 실제 통계 결과와 연구자의 해석을 구분한다.

### 9.1 RQ1 / H1

직접적인 답: T1 SRL과 중간고사 성적을 통제한 후 LCU T1은 이후 SRL T2를 정적으로 예측하였다. H1은 지지되었다.

확인된 결과: B=0.292, β=.293, 95% CI [0.165, 0.419], p<.001.

해석: 동일한 baseline SRL과 중간고사 수준을 고려했을 때 생성형 AI를 보다 학습중심적으로 활용한 학생일수록 이후 시점에서 더 높은 SRL 수준을 보이는 경향이 관찰되었다.

한계: LCU와 T1 SRL은 같은 시점에 측정되었고 LCU는 무작위로 조작되지 않았다. 따라서 LCU가 SRL을 인과적으로 증가시켰다고 결론내릴 수 없다. 측정되지 않은 학습동기, 능력, 성향 등의 대안 설명도 남아 있다.

### 9.2 RQ2 / H2

직접적인 답: T1 SRL, LCU T1, 중간고사 성적을 통제한 후 SRL T2는 이후 기말고사 성적을 정적으로 예측하였다. H2는 지지되었다.

확인된 결과: B=3.400, β=.174, 95% CI [0.569, 6.231], p=.019.

해석: 다른 모형 변수들이 동일할 때 SRL T2가 1점 높을수록 기말고사 점수는 평균 약 3.4점 높게 예측되었다.

한계: 통계적 유의성과 교육적 중요성은 동일하지 않다. 3.4점의 차이가 실제 교육적으로 중요한지 판단하려면 별도의 맥락적 기준이 필요하다. SRL이 기말고사 성적을 인과적으로 향상시켰다고 결론내릴 수 없다.

### 9.3 RQ3 / H3

직접적인 답: LCU T1과 기말고사 성적 사이에서 SRL T2를 통한 통계적 간접효과가 유의하였다. H3는 지지되었다.

확인된 주 결과: 비표준화 간접효과=0.992, 95% bootstrap CI [0.167, 2.105].

추가·보조 결과: 표준화 간접효과=.051, 95% bootstrap CI [.009, .108]. 직접효과와 총효과 역시 매개효과 해석을 위한 보조 결과로 산출되었다.

해석: 연구모형과 일치하는 LCU T1 → SRL T2 → 기말고사 성적의 통계적 간접경로가 관찰되었다.

한계: 직접효과와 총효과는 통계적으로 유의하지 않았다. 따라서 “LCU가 전반적으로 학업성취도를 높였다”고 해석할 수 없다. 또한 통계적 간접효과는 인과적 매개효과와 동일하지 않으며, SRL이 실제 인과 메커니즘임을 입증하지 않는다.

## 12. 종합

사전 계획된 주 분석에서 RQ1~RQ3에 대응하는 H1~H3는 모두 통계적 판단 기준을 충족하였다. LCU T1은 이후 SRL T2를 정적으로 예측했고, SRL T2는 이후 기말고사 성적을 정적으로 예측했으며, LCU T1과 기말고사 성적 사이에서 SRL T2를 통한 통계적 간접효과가 확인되었다.

그러나 직접효과와 총효과는 통계적으로 유의하지 않았고, 현재 연구는 비실험적 시간차 설계이므로 “LCU가 SRL을 증가시켜 학업성취도를 향상시킨다”는 인과적 결론은 내리지 않는다. 현재 자료가 지지하는 범위는 시간적으로 배열된 예측관계와 통계적 간접효과이다.

선행연구와의 비교, 교육적·이론적 시사점, 결과의 의미 확장은 자료분석 단계가 아니라 논문 작성 단계에서 문헌 근거와 함께 다룬다.
