# 문헌조사

## 1. 문헌 검색 전략

문헌 검색은 다음 세 경로를 중심으로 구성한다.

1. 생성형 AI 학습중심 활용(LCU) → 자기조절학습(SRL)
2. 자기조절학습(SRL) → 학업성취도
3. LCU → SRL → 학업성취도의 매개 메커니즘

## 2. 연구 공백

- 생성형 AI 연구는 사용 빈도, 태도, 만족도 중심의 연구가 많다.
- LCU처럼 생성형 AI 활용의 질을 측정하는 연구는 아직 제한적이다.
- LCU와 SRL의 관계를 검증한 연구는 있으나, 이를 특정 교과의 실제 시험성적까지 연결한 연구는 상대적으로 부족하다.
- 국내 연구에서는 생성형 AI 활용과 SRL, 또는 SRL과 인지된 성취도를 연결한 연구가 있으나, LCU → SRL → 객관적 시험성적의 경로를 검증한 연구는 제한적이다.
- 따라서 생성형 AI의 단순 사용 여부가 아니라 학습중심 활용의 질이 이후의 SRL과 실제 학업성취도에 어떻게 연결되는지를 시간차 자료와 baseline 변수를 통제하여 검증할 필요가 있다.

## 3. 본 연구의 차별성

1. 생성형 AI 사용량이 아닌 생성형 AI 학습중심 활용(LCU)을 측정한다.
2. LCU와 학업성취의 관계를 SRL이라는 학습과정 메커니즘으로 설명한다.
3. LCU와 SRL을 서로 다른 시점에 측정하고, T1 SRL을 통제한다.
4. 종속변수로 자기보고식 성취도가 아닌 특정 교과의 실제 기말고사 점수를 사용한다.
5. 복잡한 구조모형보다 재현성과 해석이 쉬운 회귀 기반 매개효과 분석을 적용한다.
