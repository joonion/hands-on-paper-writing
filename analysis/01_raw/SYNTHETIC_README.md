# SYNTHETIC 모의 연구 원자료

## 중요 안내

이 자료는 「생성형 AI 학습중심 활용과 대학생의 학업성취도 간의 관계:
자기조절학습의 간접효과」 연구계획을 바탕으로 생성한 **완전한 모의자료**입니다.

- 실제 학생에게서 수집한 자료가 아닙니다.
- 실제 연구결과로 보고하거나 실제 참여자의 자료로 제시해서는 안 됩니다.
- 전처리, 신뢰도 분석, 기술통계, 상관분석, 회귀분석 및 bootstrap 간접효과 분석 실습용입니다.
- 모든 원자료 파일에 `synthetic_flag = 1`을 포함했습니다.

## 파일 구성

1. `SYNTHETIC_00_roster_raw.csv`
   - 전체 모집대상 186명의 연구용 명부
2. `SYNTHETIC_01_T1_survey_raw.csv`
   - T1 설문 내보내기 형식의 원응답 183행
   - 고유 응답자 180명, 중복 응답 3행 포함
3. `SYNTHETIC_02_T2_survey_raw.csv`
   - T2 설문 내보내기 형식의 원응답 169행
   - 고유 응답자 168명, 중복 응답 1행 포함
4. `SYNTHETIC_03_exam_scores_raw.csv`
   - 186명의 중간고사 및 기말고사 원점수
5. `SYNTHETIC_raw_data.xlsx`
   - 위 네 원자료를 시트별로 모은 편의용 통합 파일
6. `SYNTHETIC_codebook.xlsx`
   - 파일 구조, 변수 정의, 문항, 값 라벨, 정제 규칙, 표본 흐름 및 생성 검증 정보
7. `simulation_parameters.json`
   - 난수 시드와 자료생성모형의 주요 설정값

## 원자료에 의도적으로 포함한 문제

- T1 중복 제출 3행
- T2 중복 제출 1행
- 연구용 ID 앞뒤 공백, 소문자, 하이픈 누락
- T2에서 명부와 연결되지 않는 ID 1건
- 비동의 2명
- 문항 불완전 응답
- T2 무응답과 시험 결시·중도포기
- 매우 짧은 응답시간 사례
- 동일 응답범주 반복 사례

## 기본 정제 원칙

1. 원자료는 읽기 전용으로 보존합니다.
2. ID의 공백 제거, 대문자화, 하이픈 형식을 표준화합니다.
3. 중복 응답은 문항 완성도가 높은 응답을 우선하고, 동률이면 더 늦은 응답을 선택합니다.
4. T1 비동의 사례와 문항 불완전 사례를 제외합니다.
5. T2 문항 불완전 사례와 명부 미연결 사례를 제외합니다.
6. 중간·기말고사 점수가 모두 확보된 사례만 주 분석에 포함합니다.
7. Likert 문자열을 1~5로 재코딩한 뒤 6문항 평균을 산출합니다.
8. 짧은 응답시간이나 동일 응답 반복만으로 자동 제외하지 않고 별도 검토합니다.

## 생성 검증 개요

고정된 난수 시드 `20260819`와 사전에 정한 확률적 자료생성모형을 사용했습니다.
최종 분석표본에서 기대되는 패턴은 다음과 같습니다.

- LCU가 T1 SRL과 중간고사를 통제한 뒤 T2 SRL을 정적으로 예측
- T2 SRL이 T1 SRL, LCU, 중간고사를 통제한 뒤 기말고사를 작게 정적으로 예측
- LCU의 기말고사 직접효과는 작고 비유의
- SRL을 통한 간접효과는 작지만 bootstrap 95% 신뢰구간이 0을 포함하지 않음

정확한 변수 정의와 생성 검증값은 `SYNTHETIC_codebook.xlsx`를 확인하십시오.
